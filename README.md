# Find Jobs

Modern full stack job portal frontend built with React, Vite, Tailwind CSS, and Laravel API integration.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- React Router DOM

## Features

- User authentication
- Company authentication
- Admin panel
- Job listings
- Company listings
- Saved jobs
- Job applications
- Responsive design
- Laravel API integration

## Backend API

This frontend connects with the Find Jobs Laravel API backend
